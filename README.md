## 🌟 Overview

**McLaren P1 GTR – Interactive 3D Automotive Experience** is a premium, cinematic, scroll-driven web experience inspired by modern luxury automotive websites.

The project combines real-time 3D rendering, cinematic storytelling, immersive animations, and interactive user experiences to showcase the McLaren P1 GTR in a visually stunning way.

Designed with modern web technologies, the experience delivers smooth transitions, realistic lighting, interactive vehicle exploration, and premium UI animations.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/mclaren-p1-gtr-3d.git
```

Navigate into the project

```bash
cd mclaren-p1-gtr-3d
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```text
http://localhost:3000
```
